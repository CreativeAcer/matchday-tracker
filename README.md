## 🧩 Everything it does

The tour above shows the flow. Open a block for the full list.

<details>
<summary><b>📅 Before the match</b> &nbsp;·&nbsp; prepare days ahead, plan the minutes</summary>

- Prepare a match days ahead: opponent, home or away, kick-off date and time, who can't make it
- Saved matches wait under **Ready to play**, earliest first, and start with one tap
- **Line-up plan**: set who plays each period (2 halves, 4 quarters or 8 short periods); **Spread evenly** shares the minutes out
- **Who's here today?** at kick-off: absent players stay off the pitch and out of the plan
- The line-up you started with is reused next match, so the bench is set once

</details>

<details>
<summary><b>⚽ During the match</b> &nbsp;·&nbsp; goals, assists, cards, minutes</summary>

- Tap a player's tile to log a goal, the score updates instantly
- Optional assists, yellow/red cards and playing time, all off by default
- The planned line-up is applied at kick-off and proposed at every break, listing who comes on and off
- On pitch / bench per player, so a benched player can't be tapped by mistake
- Live minutes on every tile, with the least-played player outlined in gold
- Own goals for either team, never credited to a player
- Running clock that keeps counting while the phone is locked
- A clock for the whole game, with the current period shown separately (**Q2 · 01:20**)
- Optional period length: the clock turns gold once the referee plays past it
- Half-time button that pauses the clock and starts a new period
- Undo, plus edit and delete on every entry in the match log, which opens in its own screen so the match screen never grows
- Correct the opponent's name mid-match if you mistyped it

</details>

<details>
<summary><b>🟨 Rules it enforces</b> &nbsp;·&nbsp; so you don't have to</summary>

- A second yellow automatically becomes a red
- A red card benches the player for the rest of the match
- Nothing can be logged before the clock is started, so every minute is accurate

</details>

<details>
<summary><b>📋 After the match</b> &nbsp;·&nbsp; report, card, season</summary>

- **Match card**: the result as a shareable picture with the score, scorers with shirt numbers and every goal's minute
- Summary with the score, goals per player and a minute-by-minute timeline, grouped by period
- Share the report as text instead, or copy it
- Season history with top scorers, re-shareable per match as a card or as text
- **Fix** any finished match: edit or delete entries and the score, scorers and season totals are recalculated

</details>

<details>
<summary><b>👥 Teams and backup</b> &nbsp;·&nbsp; several teams, one file to restore or share</summary>

- Several teams on one device, each with its own roster, settings, history and match in progress
- **Back up team data** writes one JSON file with players, settings, matches played **and matches prepared** (line-ups, period lengths and absentees), so one file restores the lot after a wipe
- Switch parts of it off to share: just the squad for a new coach, or just next week's line-up for another parent
- **Import a file** adds the data as a new team and leaves your other teams alone; replacing a team with the same name is an explicit choice
- A reminder appears when matches have been played, or preparation done, since your last backup

</details>

It is a **single self-contained HTML file** with no build step, no framework and no dependencies beyond Google Fonts.

## 🛠️ Run locally

```bash
git clone https://github.com/CreativeAcer/matchday-tracker.git
cd matchday-tracker
```

Open `index.html` in a browser and you are running it. Offline mode and installing to the home screen need the page to be served over http(s), so for those use any static server:

```bash
python3 -m http.server 8080   # then open http://localhost:8080
```

## 💾 Your data and privacy

Team and match data is stored in your browser's **Local Storage**, on this device only. Nothing is sent anywhere.

- **Back up team data** (on the Team and History screens) writes everything to one JSON file.
- **Import a file** puts it back, or loads it on another phone to move or share a team.
- Clearing your browser data removes the app's data, so keep a backup. The app tells you when one is due.

## 🌐 Hosting

The app is a static site, so it runs almost anywhere: **GitHub Pages** (the live version), Netlify, Cloudflare Pages or any static web server.
